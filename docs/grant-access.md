# Accessing the FTS Cloud

Accessing the FTS Cloud allows approved users to log in to the **Future Tools Systems backend inventory management software**, manage site data, and administer user permissions. Access must be approved by a site administrator before use.

**Also known as:** *Cloud Access*, *FTS Cloud Login*, *Backend Access*

---

## Granting Others Access (Administrators)

Administrators can grant access to additional users before entering the site dashboard.

### Grant Access

1. From the login screen, click the **gear icon** next to your site.
2. Select **Grant Access**.
3. Enter the user’s email address.
   - If the user is not registered, they will receive a registration email.
   - If already registered, access is granted automatically.

Click **Assign User** to complete the process.

---

### Advanced Permissions

- To allow a user to grant access to others, enable **“Allow user to grant others access.”**
- Use this option sparingly—this grants broad administrative privileges.

---

## Restricting User Permissions

Administrators can limit user access by:

1. Clicking **View Details** next to a user.
2. Assigning or removing module permissions.
3. Enabling **Restricted Suppliers**, if needed.
4. Clicking **Update Access** to save changes.

---

## Audit Logs

The **Audit Logs** tab within Site User Access Control displays:

- User activity history
- Actions performed
- Who performed each action

This helps administrators track changes and maintain accountability.

- Open the confirmation email sent from **ftsware**.
- Click the confirmation link labeled **“here”**.
- You will be redirected to an account confirmation page.

⚠️ **Failure to confirm your email will prevent password resets and other system emails**.

---

### Log In to the Cloud

1. Return to the **LOGIN** page on the FTS website.
2. Enter your registered **email address** and **password**.
3. (Optional) Check **Remember Me** to stay logged in.

⚠️ **Use caution**: If others have access to your computer, they may also gain administrative access if this option is enabled.

---
## FAQ

### What if I don't see the gear icon next to my site on the site list?
If you do not see the gear icon next to a site, you do not have Site Administrator access for that site. Without Site Administrator permissions, you will not be able to grant access to other users.

### Can you have more than one site administrator?
Yes. You can have as many Site Administrators as needed for each site.

### Can you edit permission on a user at anytime?
Yes. As a Site Administrator you have access to change persmission at anytime.
