# Importing Categories

Importing categories is a fast way to load items into subcategories in bulk.  
This feature allows you to efficiently assign items to groups without manually adding them one by one.

**Also known as:** *Importing Categories*, *Importing Subcategories*, *Importing Groups*

---

## What Importing Categories Is Used For

- Quickly assigning **many items** to categories and subcategories.
- Organizing items into logical groups for easier searching and purchasing.
- Reducing manual effort when managing large item lists.

---

## How to Import Categories

### Step-by-Step Instructions

1. **Navigate to the Categories Module**  
   Open the **Categories** module from the system dashboard.

2. **Create the Top Category (Group)**  
   - You must first create the **top-level category** (also known as a group).
   - Imported items will be placed under this category’s subcategories.

3. **Download the Import Template**  
   - Select the **cloud icon** in the top-right corner.
   - This will download the **category import template** (spreadsheet).

4. **Complete the Import Template**  
   Fill in the required fields, including:
   - **Top Category**
   - **Subcategory name(s)** the item should belong to
   - **Item ID (`item_id`)** for each item

   > ***Tip:*** There is no limit on subcategories. You can add addtional subcategory columns to the template if needed.

5. **Upload the Completed Template**  
   - Once the spreadsheet is complete, upload it back into the Categories module.
   - The system will process the file and assign items to the specified subcategories.

---

## Important Notes

- Items **cannot** be imported directly into a top category.
- Every imported item **must be assigned to at least one subcategory**.

> ***Tip:*** If a top category does not exist, create it before uploading your import file.
